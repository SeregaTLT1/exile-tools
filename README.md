# Exile Tools

Каталог полезных инструментов Path of Exile 1 и Path of Exile 2 на React + Vite.

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

Vercel: Framework `Vite`, Build `npm run build`, Output `dist`.

Инструменты добавляются в `src/data.js`. Избранное хранится локально в браузере.

Независимый фанатский проект, не связан с Grinding Gear Games.
